# Parameter reference

Every variable a batch spec can set (see [DATA_GENERATION.md](DATA_GENERATION.md) for the spec format).
Defaults come from `rc_drift_sim/configs/*.yaml`. **Basic** variables are the ones most worth
changing; **advanced** ones are numerical or fine-tuning settings. *Structural* settings split a
batch into separate vectorized groups when they vary.

This file is generated by `python scripts/make_param_reference.py`; do not edit it by hand.

## Maneuvers (input generators)

Set with `"maneuver": {"type": ..., "params": {...}}`; every parameter accepts a distribution.

### `drift_schedule`: Drift entry (power-over)

Straight launch, a full-throttle stab with a little steer to break the rear loose, then counter-steer with the throttle matched to the slide (the open-loop drift of the test suite).

| parameter | default | unit | description |
|---|---|---|---|
| `launch_s` | 1.4 | s | straight launch duration |
| `launch_throttle` | 0.37 | - | throttle during the launch |
| `kick_s` | 0.28 | s | duration of the throttle stab |
| `kick_steer` | 0.25 | - | steering during the stab (+ = left) |
| `kick_throttle` | 1 | - | throttle during the stab |
| `sustain_steer` | -1 | - | counter-steer while sliding |
| `sustain_throttle` | 0.226 | - | throttle while sliding (narrow band, see DESIGN.md) |
| `mirror_prob` | 0 | - | probability of mirroring the steering (left/right balance) |

### `constant`: Constant inputs

Hold one steering and throttle command for the whole episode (donuts, coast-down, cruising).

| parameter | default | unit | description |
|---|---|---|---|
| `steer` | 0.3 | - | steering command (+ = left) |
| `throttle` | 0.25 | - | throttle command |
| `mirror_prob` | 0 | - | probability of mirroring the steering (left/right balance) |

### `step_steer`: Step steer

Drive straight, then step the steering at t_step (classic yaw-response test).

| parameter | default | unit | description |
|---|---|---|---|
| `throttle` | 0.2 | - | throttle command |
| `t_step_s` | 1 | s | time of the steering step |
| `steer` | 0.4 | - | steering after the step |
| `mirror_prob` | 0 | - | probability of mirroring the steering (left/right balance) |

### `sine_steer`: Sine steer

Sinusoidal steering at constant throttle (frequency-response data).

| parameter | default | unit | description |
|---|---|---|---|
| `throttle` | 0.2 | - | throttle command |
| `amplitude` | 0.4 | - | steering amplitude |
| `frequency_hz` | 0.5 | Hz | steering frequency |
| `phase_deg` | 0 | deg | phase at t = 0 |
| `mirror_prob` | 0 | - | probability of mirroring the steering (left/right balance) |

### `chirp`: Chirp steer (frequency sweep)

Steering sine whose frequency sweeps linearly from f0 to f1 over the episode (system identification excitation).

| parameter | default | unit | description |
|---|---|---|---|
| `throttle` | 0.2 | - | throttle command |
| `amplitude` | 0.4 | - | steering amplitude |
| `f0_hz` | 0.1 | Hz | start frequency |
| `f1_hz` | 3 | Hz | end frequency |
| `mirror_prob` | 0 | - | probability of mirroring the steering (left/right balance) |

### `lane_change`: Lane change

Straight, steer one way for half a period, the other way for half a period, straight again.

| parameter | default | unit | description |
|---|---|---|---|
| `throttle` | 0.2 | - | throttle command |
| `steer` | 0.3 | - | steering amplitude |
| `t_start_s` | 0.5 | s | start of the manoeuvre |
| `half_period_s` | 0.75 | s | duration of each half |
| `mirror_prob` | 0 | - | probability of mirroring the steering (left/right balance) |

### `random`: Smoothed random inputs

Band-limited random steering and throttle (first-order low-pass filtered white noise): broad coverage of the state space for learning dynamics models.

| parameter | default | unit | description |
|---|---|---|---|
| `steer_std` | 0.4 | - | steering standard deviation |
| `throttle_mean` | 0.25 | - | mean throttle |
| `throttle_std` | 0.1 | - | throttle standard deviation |
| `bandwidth_hz` | 1 | Hz | low-pass cutoff of the inputs |
| `throttle_min` | 0 | - | lowest throttle allowed (use < 0 to allow braking) |
| `mirror_prob` | 0 | - | probability of mirroring the steering (left/right balance) |

<a id="distributions"></a>
## Distributions

| dist | fields |
|---|---|
| `fixed` | `value` |
| `uniform` | `low`, `high` |
| `normal` | `mean`, `std` |
| `loguniform` | `low`, `high` |
| `choice` | `values` |
| `bernoulli` | `p` |
| `sweep` | `values` |
| `linspace` | `low`, `high`, `num` |

Options: `"mode": "scale"` multiplies the default instead of replacing it; `"per_wheel": true`
(condition.* only) draws each wheel separately; `normal` accepts optional `low`/`high` clipping;
`choice` accepts optional `weights`.
